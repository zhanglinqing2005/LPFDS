# Frozen manuscript reproducibility archive

The full manuscript archive is maintained separately from the compact GitHub repository so that immutable release/deposit artifacts can contain large generated datasets without bloating version control.

Archive name: `LPFDS_reproducibility_package_v1.zip`

SHA-256:

`dbb008412ce2e1f55636ae6a35e933e9827ed4e7b63b76dddbc83c4e70532131`

The archive includes the complete per-seed depth array for every integer seed from 2 through 10,000,000, the 78,499-row appearance-index dataset, fixed verification samples, scripts, environment metadata, figures, and internal checksums.

The archive is ready for Zenodo deposition. A DOI is intentionally not written here until the final English LaTeX manuscript and author metadata are frozen and the actual Zenodo record exists.
