# Legacy exploratory material

Files under this directory are retained only to preserve the historical research process. They reflect the earlier exploratory stage in which standard-orbit properties were treated as computational conjectures and regression/SPSS output was used as evidence.

The current manuscript supersedes that interpretation with an exact prime-block theorem and a separate general-seed coalescence question. For current reproducibility, use `src/`, `data/`, and `docs/` at repository root.
